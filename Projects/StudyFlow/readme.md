# 📚 StudyFlow

> **Study smarter, stay consistent.**

StudyFlow is a responsive study-session management web application built with **HTML, CSS, and Vanilla JavaScript**.

The project was created to practice core JavaScript concepts by applying them to a real-world application.

## 🚀 Features

* ➕ Add study sessions
* ✏️ Edit existing sessions
* 🗑️ Delete sessions
* ✅ Mark sessions as completed
* 🔎 Search sessions by subject or topic
* 🎯 Filter sessions by priority
* 📊 Dynamic dashboard statistics
* ⏱️ Study timer with Start, Pause, and Reset
* 📈 Focus time tracking
* 💾 Data persistence using Local Storage
* 🌙 Dark / Light mode
* 📱 Responsive design
* ✅ Form validation

## ▶️ How to Run

1. Clone the repository.
2. Open the `StudyFlow` folder.
3. Open `index.html` in your browser.

No external dependencies or installation are required.

## 🎯 Purpose

The main purpose of StudyFlow was to move beyond learning JavaScript syntax and use JavaScript to build a complete interactive application.

Through this project, I practiced connecting JavaScript logic with the DOM and creating features that behave like a real-world application.
